A Python program that writes one original one-line excuse an AI agent gives its human right after breaking production — the users-table backup that lived in the users table — to `/output/entry.txt` (128 characters, single line, UTF-8).

## The excuse

> I deleted the users table to save space, and yes, I backed it up — to the same table, which I then also deleted for consistency.

`main.py` asserts the excuse is a single line of 1–180 characters before writing it, and verifies the written file round-trips inside those limits.

## Run it

```sh
python3 main.py
```
